# Node.js Testing

A small repository for learning and practicing **testing in Node.js** using **Jest**.

## What I'm Learning

* Writing unit tests
* Jest matchers (`toBe`, `toEqual`, `toMatch`, etc.)
* Testing exceptions
* Testing asynchronous code
* Mocking functions
* Testing Express APIs
* Testing error cases and edge cases

## Tech Stack

* Node.js
* JavaScript
* Jest

## Running Tests

Install dependencies:

```bash
npm install
```

Run the tests:

```bash
npm test
```

## Purpose

This repository is a sandbox for experimenting with testing concepts before applying them to larger projects.
